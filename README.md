# NeuroRehab

Plataforma de fisioterapia y neurorehabilitación basada en evidencia.

## 🌐 Sitio en vivo

**[https://jdop315-bot.github.io/NeuroRehab/](https://jdop315-bot.github.io/NeuroRehab/)**

## 📚 Contenido

- **8 patologías**: ACV, TCE, Parkinson, SGB, Neuromusculares, Lesión medular, Parálisis cerebral, Síndrome de Down.
- **19 calculadoras clínicas**: NIHSS, mRS, Fugl-Meyer, Barthel, GCS, Rancho Los Amigos, MDS-UPDRS, Hughes, mEGOS, ALSFRS-R, MG-ADL, ASIA/AIS, GMFCS/MACS/EDACS, PDMS-2, y más.

## 🛠️ Tecnologías

HTML5 · CSS3 · JavaScript vanilla.
